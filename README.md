# 🖥️ NikhilOS

### A little universe inside your browser ✨

**NikhilOS** is a browser-based desktop environment designed to feel like a small operating system running directly inside your web browser.

It combines a modern desktop interface, animated windows, apps, games, music, personalization, and local storage into one interactive experience.

---

## ✨ Features

* 🖥️ **Desktop Environment** — A complete browser-based desktop UI
* 🚀 **Animated Boot Screen** — Custom startup experience
* 📁 **Files App** — Desktop-style file interface
* 📝 **Notes App** — Write and save notes locally
* 🧮 **Calculator** — Built-in working calculator
* 🌐 **Browser App** — Browse websites from the desktop interface
* 🎮 **Games** — Play built-in mini games
* 🎵 **Music Player** — Play local music directly inside NikhilOS
* ⚙️ **Settings** — Customize the desktop experience
* 🎨 **Wallpapers** — Switch between different desktop backgrounds
* 🔊 **Sound Controls** — Toggle system sound
* 🔔 **Notifications** — Desktop-style notification system
* 🪟 **Draggable Windows** — Move application windows around the desktop
* ⛶ **Window Controls** — Minimize, maximize, and close applications
* 💾 **Local Storage** — Save notes and preferences in the browser
* 📱 **Responsive Design** — Works on desktop and smaller screens
* ⌨️ **Keyboard Shortcuts** — Quick access to selected applications

## 🎵 Music

NikhilOS supports local MP3 playback.

Place your music file here:

```text
assets/music/music.mp3
```

Then open the Music app and press **Play**.

> Browser autoplay restrictions may require you to press Play manually.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Start the desktop

Use **Live Server** in VS Code and open the generated local URL.

You can also open `index.html` directly in a browser, although Live Server is recommended.

---

## 🌐 Deploy on GitHub Pages

NikhilOS can be hosted using GitHub Pages.

1. Push the project to GitHub.
2. Open your repository.
3. Go to **Settings → Pages**.
4. Select your main branch.
5. Select the root folder.
6. Save the settings.
7. Open the generated GitHub Pages URL.

## 💾 Data & Privacy

NikhilOS stores certain preferences locally in your browser using **LocalStorage**.

This can include:

* Notes
* Theme/wallpaper preferences
* Sound preferences
* Desktop preferences

The project does not require a traditional backend server for these features.

---

## 🎯 Project Goal

The goal of NikhilOS is to explore how far a browser can be pushed to create an experience that feels more like a real desktop operating system.

Instead of simply making another webpage, NikhilOS focuses on:

**Interaction + Animation + Personalization + Fun**
